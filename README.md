# ForumGram

Forums on the Telegram network.

## Interface

- Discover connects communities by Telegram handle or invite link.
- The forum navigation can be collapsed; boards and threads use keyboard-accessible links.
- Settings includes four color themes and reading preferences. Clear Storage removes OPFS media files only, not sessions or other caches.
- Layouts adapt to mobile screens, with stacked reply controls and visible focus indicators.

## Development

- Install deps: `npm install`
- Run dev: `npm run dev`
- Build: `npm run build` then `npm run preview`
